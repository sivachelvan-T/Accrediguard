# Student → Faculty Verification Workflow

1. Student creates a project.
2. Student selects the corresponding Faculty Reviewer before creating the project.
3. The selected faculty member is stored on the project; there is no automatic faculty assignment for student-created projects.
4. Student uploads the PDF report.
5. The PDF is analyzed, but uploading alone does not submit the project.
6. Once analysis completes, the Student sees **Submit Project for Faculty Verification**.
7. Submission changes the project to **UNDER_REVIEW** and sends a notification to the selected faculty reviewer.
8. Faculty opens the assigned project and reviews the criterion evidence.
9. Faculty can approve evidence, reject evidence, mark it partial, or request revision.
10. A revision request changes the project to **REVISION_REQUIRED** and notifies the project coordinator/student workflow.
11. After revision, the student uploads a new PDF version and submits again.
12. Faculty can approve the project only after pending evidence requiring review has been resolved.

This workflow is designed for colleges where multiple courses/departments may have different faculty reviewers.
